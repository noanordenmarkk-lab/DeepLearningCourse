# PyTorch Deep Learning Course

This repository contains my code, exercises, and experiments from a PyTorch and deep learning course.

I'm using this repository to document my learning process, understand the fundamentals of neural networks, and gain hands-on experience with building, training, and evaluating deep learning models using Python and PyTorch.

## What I'm Learning

- Building neural networks with PyTorch
- Understanding weights, biases, activation functions, and loss functions
- Training and evaluating neural networks
- Exploring weight initialization and optimization algorithms
- Working with datasets using NumPy, Pandas, and scikit-learn
- Visualizing training results and experimenting with model performance
- Applying deep learning techniques to datasets such as MNIST, Iris, and other classification problems
